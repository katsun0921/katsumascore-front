# 案G レビュー指摘の修正指示

対象：`g-summary-novel.html`  
目的：ノベル風の会話と、検索・要約の一連の体験を正しく比較できるようにする。

## 1. ネタバレを表示する前に履歴から読める

**再現手順**

1. 作品の要約から「詳しく知りたい」を開く。
2. 「結末を教えて（ネタバレ）」を選ぶ。
3. 「表示する」を押さずに「履歴」を開く。

**影響**：回答画面ではネタバレを伏せているが、履歴には回答全文が表示される。利用者が開示を選ぶ前に結末を読んでしまう。

**修正方針**：ネタバレ回答は明示的に「表示する」を押すまで履歴でも伏せる。開示後の履歴表示は、会話の流れを確認できるようにする。

**確認条件**：開示前は回答画面と履歴のどちらにも結末の本文が出ず、開示後は回答と履歴から内容を確認できる。通常の回答は従来どおり履歴に表示される。

## 2. 作品を素早く切り替えると要約が混ざる

**再現手順**

1. 一覧カードから要約モーダルを開く。
2. 要約が表示される前に「次の作品」などを押す。

**影響**：先にリクエストした作品の応答が後から返り、表示中の作品と異なる要約が混ざる場合がある。

**修正方針**：要約取得ごとに対象を識別し、応答時にそのリクエストが現在の表示に対応している場合だけ描画する。検索結果へ戻る・モーダルを閉じる場合にも、古い応答を反映しない。

**確認条件**：前後の作品を連続して切り替えても、タイトル・要約・おすすめ対象が常に同じ作品の内容になる。取得中に結果へ戻る、または閉じて別の作品を開いても、以前の応答が混ざらない。

## 3. 映画リストに映画以外のカードが表示される

**再現手順**

1. モック操作で「リスト（映画）」を選ぶ。
2. 一覧のカードと、作品探しの検索結果を確認する。

**影響**：一覧にはアニメやドラマも表示される一方、作品探しは映画に絞られており、表示と検索の対象範囲が一致しない。

**修正方針**：映画リストに表示するカードを映画のみに絞る。先頭カードと残りのカード、要約モーダルの前後移動にも同じ絞り込み結果を使う。TOPは全カテゴリのままとする。

**確認条件**：映画リストに映画以外のカードが表示されず、前後移動でも映画以外に移らない。映画リストでの検索は映画に限定され、TOPでは全カテゴリを引き続き表示・検索できる。

## 作業後の確認

- TOP・映画リストの両方で、作品探し → 検索結果 → 要約 → ノベル画面 → 戻る、の流れを確認する。
- カードから直接開く要約でも、前後移動とノベル画面への遷移を確認する。
- 修正は案Gの比較に必要な範囲にとどめ、既存の共通モックデータへの影響を確認する。
