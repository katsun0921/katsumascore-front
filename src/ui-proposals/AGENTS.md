# UIモックのファイル構成

- `src/ui-proposals/` 配下のモックは、画面ごとにHTMLファイルとして作成する。
- モック固有のCSSはそのHTML内の `<style>` タグに、JavaScriptは `<script>` タグに記述する。
- 複数のモックで共通して使用するCSS・JavaScriptは、専用のファイルにまとめて参照してよい。例えば `sayo-chat/card-mock.js` は共通ファイルとして維持する。
- 画像などの素材は別ファイルとして参照してよい。
- このルールは新規作成・変更するモックに適用する。既存のモックを一括で変更する必要はない。
