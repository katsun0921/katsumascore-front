# docs/ ディレクトリ構成

KatsumaScore フロントエンドの仕様書・設計ドキュメントを管理するディレクトリ。

---

## ディレクトリ構成

```
docs/
├── README.md          — 本ファイル（構成説明）
├── FEATURE_LIST.md    — 実装済み機能の一覧（常に最新を維持）
├── features/          — 現在使用している仕様書・設計書
├── develop/           — 現在開発中の仕様書・実装 Todo
├── idea/              — アイデアのみ・未着手の仕様書
└── archive/           — 完了・見送り・旧バージョンの仕様書
```

---

## 各ディレクトリの説明

### `features/`（現在使用している仕様書）
実装済みかつ現在も参照する設計書を置く。  
新しく実装が完了した仕様書は `develop/` から `features/` へ移動する。

### `develop/`（現在開発中の仕様書）
現在進行中の実装に対応する仕様書・Todo を置く。  
設計のみ存在し未着手の場合は `idea/` へ。

### `idea/`（アイデアのみ・未着手）
実装方針は検討しているが、開発に着手していない仕様書を置く。  
開発開始時に `develop/` へ移動する。

### `archive/`（完了・見送り・旧バージョン）
以下のドキュメントを移動する：
- 実装が完了し参照不要になった仕様書
- 採用を見送った設計・調査メモ
- 新バージョンに置き換えられた旧バージョン

---

## FEATURE_LIST.md への追記ルール（IMPORTANT）

**`features/` に新しいドキュメントが追加されたとき（`develop/` からの昇格を含む）は、  
必ず `FEATURE_LIST.md` の該当セクションに追記する。**

| 追加した仕様書の内容 | FEATURE_LIST の更新セクション |
|---------------------|-------------------------------|
| 新しいページ・ルート | §1 ページ一覧 |
| API エンドポイント追加 | §2 API エンドポイント |
| コンポーネント追加 | §3 コンポーネント一覧 |
| lib 関数・hooks 追加 | §4 ライブラリ関数 / §5 Hooks |
| 型定義追加 | §6 型定義 |
| 翻訳ファイル追加 | §7 i18n |
| アーキテクチャ・設計書追加 | §10 関連ドキュメント |

---

## ドキュメント移動フロー

```
idea/ ──── 開発開始 ────→ develop/ ──── 実装完了 ────→ features/
                                │                           │
                            見送り・完了                参照不要・旧版
                                └──────────────────────→ archive/
```
